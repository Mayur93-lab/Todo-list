# Todo List Web Application

A simple and responsive Todo List web application developed using Java, Servlets, JSP, Hibernate, and MySQL. This project allows users to manage daily tasks efficiently with features like adding, updating, viewing, and deleting tasks.

## Features

* Add new tasks
* Update existing tasks
* Delete completed tasks
* View all saved tasks
* Store task data in MySQL database using Hibernate ORM
* Clean and responsive user interface

## Technologies Used

* Java
* JSP & Servlets
* Hibernate
* MySQL
* HTML
* CSS
* Bootstrap

## Project Flow

1. User enters task details through the web interface.
2. Servlet receives the request from the client.
3. Hibernate handles database operations.
4. Task data is stored in MySQL database.
5. User can view, update, or delete tasks anytime.

## Database

The project uses MySQL database for storing todo tasks and Hibernate ORM for database connectivity and object mapping.
